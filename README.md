# About Me:
I am a Computer Science graduate from the National University of Computer and Emerging Sciences (FAST-NUCES) with hands-on experience in full-stack software development, AI-integrated applications, cloud technologies, and mobile development.

I have worked on full-stack applications, building and integrating frontend and backend systems while incorporating AI capabilities into real-world software solutions. My experience includes working with technologies such as React, Angular, Node.js, NestJS, PostgreSQL, React Native and AWS, along with developing applications that leverage AI and LLM-based technologies.

Previously, I gained practical experience through software engineering and internship roles, as well as serving as a Teaching Assistant for Object-Oriented Programming at university. These experiences strengthened my understanding of software development, problem-solving, and building maintainable and scalable applications.

I am passionate about continuously learning new technologies, improving my engineering skills, and building practical solutions that create meaningful impact.
